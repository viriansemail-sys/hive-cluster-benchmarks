Same model. Same three boxes. Up to 37% faster.

GLM-5.3-Flash ships with a small built-in helper layer that guesses the next words ahead of time (multi-token prediction, MTP). The big model checks two guesses at once, so it keeps more words per pass with no change in answer quality. We switched it on and reran the exact same test as the plain run.

Plain vs. MTP, same three boxes, same test

The Hive Benchmarking Stack (llama-benchy 0.4.0): prompts of 512 and 2,048 tokens, 128-token answers, with no history and with 4,096 tokens of history. Each test runs 3 times. Both runs used the same file, engine, boxes and split; the only change is the MTP helper.

Answer speed

tokens per second · higher is better

23–37% faster at every size. This is the number you feel: words appear about a third quicker.

Prompt reading

tokens per second · higher is better

Flat, within 1–4%. The helper only works on the answer, not on reading the prompt, so this is what we expected.

Wait for the first word

seconds · lower is better

About the same, 2–4% longer. Prompt reading still sets the wait; the faster network link is the lever for this one.
PlainMTP on, 2 guesses

Temperatures

CC does the most work as the head and now runs the helper too. It peaked at 183 °F, 5 °F above the plain run and well under the 203 °F automatic stop. Spark matched the plain run at 144 °F. Corsa's logger stopped right after it started, so Corsa has no reading for this run; its only reading, at the start, was 109 °F.

red line = 203 °F automatic stop

Room on each box, measured with MTP loaded

The helper costs memory on the head. CC went from ~69 GB to ~74 GB; the workers barely moved. There's still real room on every box.

AMD boxes: 96 GB is set aside for the GPU (the rest of the 128 GB runs Windows). Spark shares one 121 GB pool with Linux and its live services, so its free number is what's free for anything.

Where this sits on the ladder

Adding boxes adds room. The MTP helper adds speed without adding a box. Bar widths are pooled model memory; dashed lines are each model's file size.

Next speed levers: a faster link for Spark (1 Gb now, 10 Gb possible) for the first-word wait, and trying 1 or 3 guesses per step as separate recorded runs. MTP acceptance is summed over every logged request, including warm-ups. Load: tensor split 75,50,75 in load order (Corsa, Spark, CC), 32K context, head started with -lm mmap.
